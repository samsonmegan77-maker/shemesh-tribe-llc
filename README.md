# SheMesh Family Hub

Build a complete, clean, modern, mobile-first web app called SheMesh.



This is a public demonstration version only. Keep all language simple and public-facing. Do not include any technical, legal or internal system terms.



### Design Style

- Clean, calm and professional

- Colours: deep navy (#0F172A), warm gold (#B45309), white, light grey

- Mobile-first and fully responsive

- Large readable text, good spacing, simple icons

- Friendly and easy to use



### Pages to build



1. Landing Page

- Logo + “SheMesh”

- Big headline: “Everything you need, in one place”

- Subtext: “Practical tools for South African families, founders, young people and communities”

- Three clear buttons:

  - Primary: “Take Free Overload Audit”

  - Secondary: “Register”

  - Secondary: “Login”

- Short benefits: Free to start • Simple language • Built for mobile

- Section below: “Explore the 12 sections”

- Grid of 12 clickable cards with icons and short names



2. Register Page

- Full Name

- Email

- Password

- Confirm Password

- Button: “Create Account”

- Link to Login



3. Login Page

- Email

- Password

- Button: “Login”

- “Forgot password?” link

- Link to Register



4. Dashboard (after login)

- Welcome message with user’s first name

- Grid of the same 12 section cards

- Top navigation: Logo | Dashboard | Profile | Logout



5. Free Overload Audit

- 20 short questions (5 each for Time, Energy, Financial, Stress)

- Progress indicator (e.g. Question 3 of 20)

- At the end show Results page with:

  - Overall Load Score (out of 100)

  - Biggest pressure point

  - Five simple recommended actions

  - Button: “Download my summary”

  - Button: “Save results & create account”

  - Button: “Back to Home”



6. The 12 Section Pages

Create a page for each of these exact names:



1. Money & Digital Tools

2. Jobs & Youth

3. Safety & Rules

4. City & Community

5. Personal Assistant

6. Smart Checking Tools

7. Learning & Education

8. Land, Homes & Growing

9. Skills & Practical Projects

10. Stories & Media

11. Food & Community Share

12. Family Health



Each section page must contain:

- Section title

- Short friendly description (2–3 sentences)

- Simple free starter content or helpful tip

- Button: “Unlock Full Access”

- Button: “Back to Dashboard”



### Extra requirements

- All pages must be linked and fully clickable

- User can go from Landing → Register/Login → Dashboard → any Section → back

- User can take the full Overload Audit from the Landing page

- Keep the design consistent across every page

- This is a public demonstration only — focus on clean UI and good user experience



Build the complete working app with all pages connected.
