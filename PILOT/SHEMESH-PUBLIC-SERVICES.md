# SheMesh Tribe LLC — Public Product & Service Layer

Every pilot organisation receives a public-safe gateway into the SheMesh Tribe LLC ecosystem. The organisation can expose or promote services appropriate to its community while keeping SheMesh proprietary implementation details private.

## Public-facing SheMesh areas

- SheMesh public information and community resources
- Educational Hub
- DigiHustle SA
- Help Improve Unemployment resources
- AI Butler and public AI-use resources
- CivicPulse / public civic information resources
- Security awareness resources
- Food-security and resilience resources
- Tenant Protection resources
- Overload Audit / Overload Audit Lite
- Signature Series
- Side-Hustle Workbooks
- public learning, employment, household and community tools released by SheMesh Tribe LLC

## Public-safe rule

The organisation sees the **service experience**. It does not receive or publish:

- proprietary source code
- private algorithms or algorithm logic
- SATCE implementation details
- Megan Algorithm implementation details
- INDLOVU implementation details
- confidential governance architecture
- security secrets
- internal forensic methods
- credentials
- private company records
- unpublished research or patent-sensitive technical material

## Organisation experience

The SheMesh layer should feel like a useful part of the organisation's application, not an unrelated external website.

Users can discover public SheMesh resources, complete public tools and return to the organisation's own workflows without crossing the organisation's private data boundary.
