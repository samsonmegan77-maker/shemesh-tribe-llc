# Bambanani Community Care — SheMesh Pilot App

## Isolation

This is a dedicated organisation application. Bambanani users and records are isolated from Southdale Baptist and Flames of Hope.

- Home
- About
- Community care
- Feeding and soup kitchen

- Impact

- SheMesh public resources
- Login

## Core roles

### Director / Organisation Lead
Dashboard: organisation overview, today's activity, feeding, donations, sponsors, volunteers, projects, outstanding approvals, risks, reports and impact.

### Administration
Dashboard: people, documents, correspondence, calendar, registrations, tasks and records.

### Feeding / Soup Kitchen Coordinator
Dashboard: locations, food stock, volunteers, preparation, servings, people reached, shortages, incidents and session close-out.

### Kitchen Worker
Mobile task view: receive food → weigh → prepare → serve → reconcile → close.

### Outreach Worker
Dashboard: assistance requests, services delivered, referrals, follow-ups, locations and evidence.

### Youth / Community Programme Worker
Dashboard: activities, attendance, participants, events and follow-ups.

### Volunteer
Dashboard: assigned shifts, check-in/out, tasks, hours, announcements and evidence.

### Donor / Sponsor
Public-safe impact view: contributions, approved allocations, programme outcomes and aggregate impact.

## Feeding evidence chain

Sponsor/resource → allocation → procurement → stock → food batch → weight → servings → distribution → people reached → reconciliation → impact.

Where compatible hardware is available, a connected scale or phone workflow may record measurements. The system must never imply that a photograph alone proves an exact quantity.

## Director journey

Login → Director Dashboard → review exceptions and today's operations → approve/assign → monitor programmes → review impact → generate reports.

## Volunteer journey

Invite → onboarding → choose/receive assignment → check in → perform task → submit evidence → check out → feedback.

## Public-safe SheMesh layer

Expose useful public SheMesh products/services without exposing proprietary implementation details, source code, trade secrets, private algorithms, credentials or confidential records.
