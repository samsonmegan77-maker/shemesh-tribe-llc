# SheMesh Tribe LLC — Community Organisation Pilot

This directory contains the **public-safe pilot specification and prototype scaffolding** for three isolated organisation applications delivered by SheMesh Tribe LLC:

1. Bambanani Community Care
2. Southdale Baptist Church
3. Flames of Hope

## Pilot principle

Each organisation receives its own application environment, users, roles, dashboards, workflows, records and branding. Organisation operational data must remain isolated between organisations.

SheMesh Tribe LLC provides the public-facing product and service layer plus platform support, analytics and improvement measurement.

## Public-safe boundary

This repository contains only information suitable for public release. It must not contain:

- source code for proprietary algorithms
- trade secrets
- private architecture
- credentials, API keys or tokens
- confidential client records
- beneficiary personal information
- private financial records
- security-sensitive implementation details
- patent-sensitive technical disclosures

The public version describes what the products and services do, not confidential implementation details.

## Pilot environments

### Bambanani Community Care
Community-care, feeding, outreach, volunteer, donor and resource workflows.

### Southdale Baptist Church
Church leadership, pastoral support, ministries, members, volunteers, outreach, events and administration workflows.

### Flames of Hope
Multi-programme community development covering food, education, healthcare, children/youth, skills, outreach, projects, volunteers, sponsors and monitoring & evaluation.

## SheMesh pilot console

SheMesh Tribe LLC requires a separate platform-side environment for:

- aggregate product analytics
- user-journey measurement
- feature adoption
- workflow completion
- error and usability tracking
- pilot feedback
- issue management
- cross-pilot product improvement
- pilot matrix scoring

SheMesh analytics should use the minimum information necessary and prefer aggregate/de-identified measurements where individual-level information is not required.

## Status

Pilot architecture and public-safe requirements are being prepared before production deployment. Production authentication, database isolation, hosting, backups, monitoring and security configuration must be completed before real organisational data is used.
