# Southdale Baptist Church — SheMesh Pilot App

## Isolation

This is a dedicated church application. Southdale Baptist users and records are isolated from Bambanani and Flames of Hope.

## Public site

- Home
- About
- Faith/community information
- Ministries
- Events
- Outreach
- Volunteer
- Giving
- Community support
- News/announcements
- Resources
- Contact
- SheMesh public resources
- Login

## Core roles

### Pastor / Pastoral Lead
Dashboard: pastoral responsibilities, appointments, support/prayer requests, follow-ups, ministry oversight, calendar and urgent tasks.

### Church Leadership
Dashboard: church overview, ministries, programmes, people, volunteers, outreach, finance summaries, decisions, tasks and reports.

### Church Administrator
Dashboard: member records, documents, correspondence, calendar, bookings, events, tasks and administration.

### Treasurer / Finance
Dashboard: giving, donations, expenses, budgets, projects, approvals and reports.

### Ministry Leader
Dashboard: ministry participants, activities, attendance, volunteers, schedules, resources and follow-ups.

### Outreach Coordinator
Dashboard: community assistance, food/outreach activities, referrals, people reached and follow-ups.

### Volunteer
Dashboard: opportunities, shifts, tasks, check-in/out, hours and announcements.

### Member
Dashboard: events, announcements, ministry participation, volunteering, approved resources, giving and requests.

## Pastoral privacy

Sensitive pastoral information must be separately permissioned and should not appear in general organisation dashboards. Users receive only the minimum access needed for their role.

## User journeys

Member: discover → register → participate → request support → follow-up.

Volunteer: discover opportunity → accept → check in → serve → check out → record hours.

Pastor: request/appointment → review → action → follow-up → close.

Leader: dashboard → review → assign/approve → monitor → report.

## Public-safe SheMesh layer

Provide access to useful public SheMesh products/services while keeping SheMesh proprietary implementation, trade secrets, private algorithms, credentials and confidential company material outside the public application.
