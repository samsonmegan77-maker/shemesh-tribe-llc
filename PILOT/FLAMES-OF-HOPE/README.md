## Role dashboards

### Founder / Chairperson
Executive dashboard: strategy, organisational performance, governance, programmes, funding, risk, approvals and impact.

### Executive Director
Management dashboard: operations, programmes, staff, volunteers, budgets, beneficiaries, deadlines, approvals and reports.

### Operations Director
Operations dashboard: daily activities, locations, staffing, volunteers, supplies, incidents, tasks and exceptions.

### Administration Manager / Secretary
Administration dashboard: documents, records, correspondence, calendar, registrations, tasks and approvals.

### Treasurer
Finance dashboard: income, expenditure, donations, sponsorships, budgets, allocations, approvals and financial reports.

### Project Manager
Project dashboard: projects, milestones, beneficiaries, resources, assignments, evidence and completion.

### Children / Programme Officer
Programme dashboard: participant records, activities, attendance, services, referrals, safeguarding flags and follow-ups.

### Monitoring & Evaluation
M&E dashboard: indicators, targets, outputs, outcomes, evidence, programme statistics and impact reports.

### Marketing / News / PR
Communications dashboard: campaigns, events, approved media, public stories, announcements and publication workflow.

### Healthcare / Skills / Education / Sports Programme Workers
Programme-specific dashboards with only the records and tasks required by each programme.

### Kitchen / Feeding Worker
Mobile dashboard: receive → weigh → prepare → serve → reconcile → close.

### Volunteer
My shifts, tasks, check-in/out, hours, training, announcements and evidence.

### Sponsor / Donor
Public-safe impact view: contribution, approved programme allocation, aggregate outputs and outcomes.

## Core impact chain

Sponsor → contribution → allocation → resource → programme → service delivered → people reached → evidence → outcome → impact report.

## User journeys

Sponsor: discover → contribute → select/approve programme → receive impact update.

Programme worker: login → today's tasks → deliver service → capture evidence → submit → follow-up.

Project manager: project → milestones → assignments → resources → evidence → completion → report.

M&E: define indicator → collect evidence → validate → analyse → report.

Director: executive dashboard → exceptions → decisions/approvals → programme review → impact → reporting.

## Public-safe SheMesh layer

The application can expose public SheMesh products/services, learning resources and tools. It must not expose proprietary source code, private algorithms, trade secrets, credentials, confidential architecture or sensitive organisational records.
