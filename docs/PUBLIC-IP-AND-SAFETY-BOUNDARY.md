# Public IP & Safety Boundary

This repository is a public-facing application surface. It should contain only material deliberately cleared for public release.

Public visibility does not by itself transfer ownership, place an original work in the public domain, waive intellectual-property rights, or grant unrestricted permission to reproduce, commercialise, modify or redistribute protected material.

Some original SheMesh systems, methods, educational materials, designs, written works and inventions may be creator-owned and made available to SheMesh Tribe LLC under separate licensing arrangements. This repository is not itself a licence or assignment.

Do not publish:

- proprietary algorithms or protected implementation details;
- confidential methodologies or internal operating procedures;
- unpublished inventions or patent-sensitive technical details;
- private source code that reveals protected internal machinery;
- private datasets or personal/customer/participant information;
- credentials, API keys, passwords, private keys, recovery codes or access tokens;
- confidential infrastructure or partner information;
- confidential commercial agreements; or
- private pilot credentials or operational codes.

Keep protected masters, invention records, development evidence, private implementations and signed licensing documents in a controlled private location.

If protected or secret material is accidentally published, remove it from the current public tree, preserve an incident record, and rotate/revoke exposed credentials. Removal from the current tree does not necessarily remove material from Git history or third-party copies.
